## 环境踩坑记录（重要，可复用）
1. **Git Bash 路径转换坑**：`/c/Users/...` 传给 Windows Python/pip 会被转成 `C:\c\Users\...`
   - 后果：`pip install --target` 装到 C:\c（垃圾目录，已清理）、venv 创建"成功"但目录不存在
   - 解法：命令前加 `MSYS_NO_PATHCONV=1`，并用 Windows 风格路径 `C:/Users/...`
2. **venv 在此环境创建失败**（`python -m venv` 静默失败，无目录产出）
   - 解法：改用 `pip install --target <隔离目录>` + 脚本内 `sys.path.insert`
3. **Read 工具读不了 PDF**（报 binary file）
   - 解法：用 pypdf 解析，已装到 `C:\Users\Administrator\.workbuddy\binaries\python\pkgs`

## 浏览器自动化环境踩坑（可复用）
1. **`agent-browser` 未装**，装它要下载 Chromium ~500MB，太重
2. **系统 Edge headless 直接失败**：因为 Edge 已在运行（`正在现有浏览器会话中打开`），命令行参数被转发到现有实例，headless 不生效。`--headless=new` 和 `--headless=old` 都无效
3. **解法**：Python + `playwright`（仅装 Python 包 ~40MB），用 `channel="msedge"` 复用系统 Edge，跳过 Chromium 下载
4. **对比**：playwright(40MB) << agent-browser(500MB)，优先选 playwright
